Projects

Project 1: The Challenge

The Challenge was my first semester project. Our group worked on the problem of ghost nets and built a solution that combined software, hardware and security. The project was large, so we divided the tasks. I focused mainly on the database, security and documentation, while other teammates worked on the hardware and the GPS‑module. We had to design and build the application ourselves. My part was to create the database structure, write the queries, and make sure the application could store and retrieve data correctly. I also worked on the security section, where we documented risks and implemented basic measures such as password rules and role‑based access. Besides the software, our group also worked with hardware. We used an Arduino and a GPS‑module to read coordinates and send them to the application. Even though I was not the one connecting the hardware, I helped with the documentation and understanding how the hardware and software worked together. This project taught me how to collaborate in a bigger team, how to split tasks, and how to combine different parts into one working solution. I learned more about Java, databases, security and how to build an application from scratch.

Project 2: Hotel Simulator

Building a hotel simulation was the project in the second semester. For this assignment we had to create a working hotel simulation in Java. We received a set of external libraries that contained the layouts and scenarios, and our task was to write the code that connected everything together so the simulation could actually run. The simulation included different hotel scenarios, such as guests going to activities, a fire alarm where all guests had to leave the hotel, switching between multiple layouts, and more. We also had to design a simple GUI so the simulation looked clear and the user could load different scenarios, change the speed of the simulation, and interact with the system. This project was more complex than the first one, because we had to understand the given libraries and make our own code work with them. Everyone in the group programmed, and the collaboration went well. I learned a lot about Java, debugging, reading code from others, and building logic that works with external libraries. This project helped me improve my programming skills and understand how larger simulations are built.
