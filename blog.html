My First Semester

In my first semester I stepped into a completely new world, because I had never programmed before. We had six different subjects and a big project that we worked on throughout the whole semester, and since everything was new it took some time to get used to everything. I discovered that I enjoyed security and programming the most, which helped me choose the software engineering differentiation. Even though the semester was intense, I learned a lot and became more confident in my skills. Looking back, I’m happy with the choice I made and with how much progress I’ve made since then.

Working on The Challenge

Working on The Challenge was my first experience with a bigger project. We were with six people, so we divided the tasks to make the work manageable. Three teammates focused on programming and hardware, while the other three, including me, worked on the database and security. I also worked on the documentation together with another teammate. Because everyone was working on different parts, we had to keep each other informed so the whole project stayed consistent. The collaboration went well, and everyone knew what the others were doing. I learned how important communication and coordination are in a larger project, and it gave me a better idea of how teamwork in software engineering works.

Java in Semester 2

In the second semester I started working with Java more seriously, and it felt like a real beginning in writing code. We received a lot of new material about how Java works, which made the start a bit challenging. With self‑study and the lessons it became easier, and I managed to pass the semester in one go. Working in a group in which everyone had the same task was new, especially when we had to merge each other’s code. In the beginning it was difficult to avoid conflicts, so we split the work and made sure no one edited the same classes. Using the class diagram helped us stay organized, and after a few weeks the collaboration went much smoother. This project taught me a lot about Java, teamwork and how to work in a structured way.
