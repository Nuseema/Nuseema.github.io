My First Semester

My first semester was mostly about getting used to everything. I had never programmed before, so a lot of things felt new. With six subjects and a project running the whole semester, it took some time to find a rhythm. Step by step I learned how to study, how to work with code, and how to stay organized. It was challenging, but it gave me a good foundation for the rest of the study.

Working on The Challenge

The Challenge was my first project. Our group divided the tasks so everyone could focus on their part. I worked on the database, security and documentation. Others handled the hardware and GPS module. We had to communicate well to keep everything consistent. It taught me how teamwork works in practice and how important structure is in a project.

Java in Semester 2

In the second semester I started working with Java more seriously. The beginning was a bit difficult because there was a lot of new material, but after practicing it became clearer. I learned how to write cleaner code, how to debug, and how to work with larger codebases. Working in a group also helped me understand how to merge code properly and stay organized.
